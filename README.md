# 「プロダクト名称」

## ***stroly***


# エレベータピッチ
**お出かけをもっと楽しく**したい
**写真愛好者**向けの
**位置情報連動型写真共有アプリ**を実現する
**stroly**です。
これは**撮った写真をマップ上に記録し、季節や天気ごとに楽しむこと**ができ、
**Instagram**とは違って、
**リアルな場所での交流と写真の新たな楽しみ方が可能**が備わっています。


# 想定利用者像

外出時によく写真を撮る人​

# 想定利用状況

- 撮った写真は蓄積されるだけで、思い出と結びつかない
- 毎日同じ道の往復で変わらない毎日を送っている
  
上記のような人に向けて、写真の管理と新しい発見を提供し、お出かけをもっと楽しくなるような体験を提供する。

# プロダクトの説明

このアプリは、日々の散歩や旅行をより魅力的にするための写真共有・閲覧アプリです。撮影した写真は位置情報を添えてマップ上にピンとして表示され、訪れた場所を簡単に記録・共有できます。公開範囲は自由に設定可能です。このアプリで、季節や時間帯ごとの風景を写真で捉え、共有することで、新しい発見や再訪のきっかけを提供します。毎日のお出かけや特別な旅行を、もっと楽しく、もっと思い出深い体験に変えましょう。
